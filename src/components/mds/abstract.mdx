# Abstract

Existing sketch generation methods often rely on image guidance and are largely limited to individual objects or simplified scenes, leaving text-guided generation of multi-concept scene sketches underexplored. We present SketchClaw, an automated framework that mimics the human sketching workflow through coding agents.
Given a scene-level text prompt, SketchClaw first employs a large language model (LLM) to decompose the scene into multiple draft assets, where each is represented by a set of B\'ezier curves. Then, an agentic reasoning loop iteratively plans, executes, and verifies their spatial arrangement, guided by multimodal feedback and hierarchical self-evolution correction. Finally, a structure-aware refinement module leverages diffusion priors to enhance sketch quality while preserving geometric structure. To support future research and applications in multi-concept scene sketch generation, we further introduce the MCSketch8K dataset, comprising editable vector assets, compositional layouts, and object-level manipulation annotations. Extensive experiments show that SketchClaw outperforms state-of-the-art baselines in object modularity, layout alignment, and structure-preserving refinement.
